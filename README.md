# Full Stack Study

Repositório dedicado aos meus estudos de desenvolvimento full stack, com exemplos, exercícios e projetos práticos.

## Objetivo

Registrar minha evolução de forma organizada, reunindo conteúdos de estudo e práticas de cada etapa da formação full stack.

## Stack planejada

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Node.js
- Express
- PostgreSQL
- Prisma
- Git
- GitHub

## Estrutura

```text
fullstack-study/
├── README.md
├── resources/
│   └── roadmap.md
└── 01-html/
    ├── examples/
    │   ├── 01-introduction/
    │   ├── 02-elements/
    │   ├── 03-quotations/
    │   ├── 04-colors/
    │   └── 05-css/
    └── exercises/
```

As pastas em `examples` reúnem demonstrações por tema. A pasta `exercises` contém as práticas numeradas de HTML.

Abra qualquer arquivo `.html` diretamente em um navegador. Os exemplos atuais não exigem instalação de dependências nem etapa de build.
